# Journal Format

DoubleBook uses a plain-text format compatible with [hledger](https://hledger.org/). This guide covers the complete syntax.

## Basic Structure

A journal file contains **transactions**. Each transaction has:

1. A **date** and **description** on the first line
2. Two or more **postings** (account + amount) on indented lines
3. Postings must **balance to zero**

```plaintext
2025-01-15 Coffee Shop
    expenses:dining          $4.50
    assets:checking         -$4.50
```

## Transaction Syntax

### Date Formats

```plaintext
2025-01-15 Standard format (YYYY-MM-DD)
2025/01/15 Alternative with slashes
2025.01.15 Alternative with dots
```

### Status Markers

```plaintext
2025-01-15 Uncleared transaction
    ...

2025-01-15 * Cleared transaction (reconciled)
    ...

2025-01-15 ! Pending transaction
    ...
```

### Description

The description follows the date (and optional status):

```plaintext
2025-01-15 Simple description
2025-01-15 * Multi word description here
2025-01-15 Description | with payee
```

## Postings

### Basic Posting

Each posting is indented and contains an account and amount:

```plaintext
2025-01-15 Example
    expenses:food:groceries     $50.00
    assets:checking            -$50.00
```

### Inferred Amount

The last posting amount can be omitted (will be calculated):

```plaintext
2025-01-15 Example
    expenses:groceries          $50.00
    assets:checking
    ; Amount will be inferred as -$50.00
```

### Multiple Postings

Transactions can have more than two postings:

```plaintext
2025-01-15 Split transaction
    expenses:food:groceries     $30.00
    expenses:food:snacks        $15.00
    expenses:household           $5.00
    assets:checking            -$50.00
```

## Amounts

### Currency Symbols

```plaintext
$100.00      ; USD (prefix)
100.00 USD   ; USD (suffix)
€50.00       ; Euro
£75.00       ; British Pound
¥1000        ; Yen
100 STOCK    ; Commodities
```

### Decimal Places

```plaintext
$100         ; No decimals
$100.5       ; One decimal
$100.50      ; Two decimals
$100.123     ; Three decimals (for crypto, etc.)
```

### Negative Amounts

```plaintext
-$100.00     ; Explicit negative
$-100.00     ; Also valid
($100.00)    ; Parentheses (accounting style)
```

### Thousand Separators

```plaintext
$1,000.00    ; Comma separator
$1 000.00    ; Space separator
```

## Account Names

### Hierarchy

Use colons to create account hierarchies:

```plaintext
assets:bank:checking
assets:bank:savings
expenses:food:groceries
expenses:food:dining
income:salary:main-job
```

### Naming Conventions

- Use **lowercase**
- Separate words with **hyphens** or **underscores**
- Start with top-level category

### Standard Top-Level Accounts

| Account | Description |
|---------|-------------|
| `assets` | Things you own (cash, bank, investments) |
| `liabilities` | Things you owe (loans, credit cards) |
| `equity` | Net worth, opening balances |
| `income` | Money received (salary, interest) |
| `expenses` | Money spent (food, rent, utilities) |

## Comments

### Line Comments

```plaintext
; This is a comment
# This is also a comment

2025-01-15 Transaction
    ; Comment on posting
    expenses:food    $20.00
    assets:cash     -$20.00   ; Inline comment
```

### Block Comments

```plaintext
comment
This is a multi-line comment.
Everything here is ignored.
end comment
```

## Tags

Add metadata with tags:

```plaintext
2025-01-15 Business Lunch ; client:acme, project:website
    expenses:business:meals    $45.00
    assets:business:checking  -$45.00
```

### Tag Syntax

```plaintext
; tag:value     ; Key-value tag
; tag:          ; Tag with empty value
; tag           ; Boolean tag (just the key)
```

## Directives

### Account Declaration

```plaintext
account assets:checking
account expenses:food:groceries
```

### Commodity Declaration

```plaintext
commodity $
    format $1,000.00
```

### Include Other Files

```plaintext
include ~/finances/2024.journal
include monthly/*.journal
```

## Multi-Currency

### Direct Conversion

```plaintext
2025-01-15 International Purchase
    expenses:travel       €100.00 @ $1.08
    assets:checking      -$108.00
```

### Total Price

```plaintext
2025-01-15 Stock Purchase
    assets:investments    10 AAPL @@ $1500.00
    assets:checking      -$1500.00
```

## Balance Assertions

Verify account balance at a point:

```plaintext
2025-01-15 Reconciliation
    assets:checking    $0.00 = $1234.56
    ; Assert balance is exactly $1234.56
```

## Complete Example

```plaintext
; Personal Finance Journal
; ========================

account assets:checking
account assets:savings
account expenses:food
account expenses:utilities
account income:salary

; Opening balances
2025-01-01 * Opening Balance
    assets:checking          $5,000.00
    assets:savings          $10,000.00
    equity:opening         -$15,000.00

; Regular transactions
2025-01-05 * Grocery Store
    expenses:food:groceries     $78.50
    assets:checking

2025-01-10 * Paycheck ; employer:acme
    assets:checking          $2,500.00
    income:salary

2025-01-15 Electric Company
    expenses:utilities:electric  $95.00
    assets:checking

2025-01-20 ! Pending Transfer
    assets:savings            $500.00
    assets:checking
```
