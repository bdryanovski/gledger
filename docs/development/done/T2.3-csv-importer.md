# T2.3 — CSV Importer with Encoding Support and Deduplication

## Goal
Implement the CSV import pipeline: read a CSV file with encoding conversion, apply
the importmap column mappings, generate unique IDs per row, skip duplicates already
in the journal, and return a list of new transactions to append.

## Context
Users will import bank CSV exports. The key challenges are: encoding (many banks
export in non-UTF-8 encodings), column mapping (different banks use different layouts),
deduplication (re-importing the same file should not create duplicate entries), and
currency (amounts may be in a non-base currency).

**Depends on:** T2.2 (importmap), T1.5 (parser/AST), T1.6 (journal writer)
**Blocks:** T2.4 (CLI import command uses this)

## Create `importer/csv.go`

### Main import function

```go
package importer

// ImportResult holds the result of an import operation.
type ImportResult struct {
    Imported   []*ast.Transaction // new transactions to append
    Skipped    int                // count of duplicate rows skipped
    Errors     []ImportError      // non-fatal errors (rows that couldn't be parsed)
    TotalRows  int                // total data rows in the CSV (excluding header)
}

// ImportError holds info about a row that failed to parse.
type ImportError struct {
    Row     int
    Content string
    Reason  string
}

// ImportCSV reads the CSV at csvPath using the provided importmap,
// skips rows whose IDs already exist in existingIDs, and returns
// new transactions.
func ImportCSV(csvPath string, imap *ImportMap, existingIDs map[string]bool) (*ImportResult, error)
```

### Implementation steps inside `ImportCSV`:

#### Step 1: Encoding conversion
```go
import "golang.org/x/text/encoding/charmap"
import "golang.org/x/text/transform"
```

- If `imap.Encoding` is `"utf-8"` or `"utf8"` (case-insensitive), read as-is
- If `imap.Encoding` is `"windows-1251"` or `"cp1251"`, wrap the reader with
  `transform.NewReader(f, charmap.Windows1251.NewDecoder())`
- If `imap.Encoding` is `"iso-8859-1"` or `"latin-1"`, use `charmap.ISO8859_1`
- If `imap.Encoding` is `"windows-1252"`, use `charmap.Windows1252`
- If unknown, return an error

#### Step 2: CSV parsing
```go
import "encoding/csv"
```

- Set `csv.Reader.Comma` to the delimiter rune from `imap.Delimiter`
  - Handle multi-char delimiters (e.g., `"||"`) by using only the first rune,
    or if delimiter is more than 1 char, implement a custom line splitter
  - For pipe `|`, set `Comma = '|'`
- Set `csv.Reader.LazyQuotes = true` (bank CSVs often have inconsistent quoting)
- Set `csv.Reader.FieldsPerRecord = -1` (variable number of columns)
- Skip the first `imap.SkipLines` lines

#### Step 3: Row processing
For each row:
1. Extract fields using `imap.Columns`:
   - `date = row[imap.Columns.Date]`
   - `description = row[imap.Columns.Description]` (if index ≥ 0)
   - Determine amount:
     - If `imap.Columns.Amount >= 0`: use that column (positive = credit, negative = debit)
     - If both debit and credit columns set: use debit if non-empty, credit if non-empty
     - Both empty → skip row (treat as header or empty row)
   - `reference = row[imap.Columns.Reference]` if index ≥ 0

2. Parse the date using `imap.DateFormat` with `time.Parse`

3. Clean the amount string:
   - Remove commas: `strings.ReplaceAll(s, ",", "")`
   - Trim spaces
   - Parse as float64

4. Determine amount sign:
   - If using debit/credit columns: debit = negative (money out), credit = positive (money in)
   - If using combined amount column: use the sign from the CSV

5. Generate unique ID:
   ```go
   func generateRowID(date, amount, reference, description string) string {
       // Prefer reference if available (bank's own unique ID)
       // Otherwise hash date+amount+description
       key := reference
       if key == "" {
           key = date + "|" + amount + "|" + description
       }
       h := sha256.New()
       h.Write([]byte(key))
       return fmt.Sprintf("%x", h.Sum(nil))[:16]
   }
   ```

6. Check if ID already exists in `existingIDs` → if yes, increment `Skipped`, skip row

7. Apply transforms: iterate through `imap.Transforms`, check if any match this row,
   apply overrides for debit/credit account and tags

8. Build `*ast.Transaction`:
   ```
   YYYY-MM-DD Description
       ; id: <generatedID>
       ; source: <importmap.Name>
       [tag lines if any transforms matched]
       <sourceAccount>               [signed amount] [currency]
       <debitOrCreditAccount>
   ```
   The second posting (debit/credit account) has the implied/opposite amount.

9. Add the transaction to `result.Imported` and the ID to a local seen-map
   (to handle duplicates within the same CSV file)

#### Step 4: Return result

## Create `importer/dedup.go`

```go
// ExtractIDs reads an existing journal and returns a set of all transaction IDs.
// Returns an empty map if the journal has no transactions with IDs.
func ExtractIDs(transactions []*ast.Transaction) map[string]bool {
    ids := make(map[string]bool)
    for _, txn := range transactions {
        if txn.ID != "" {
            ids[txn.ID] = true
        }
    }
    return ids
}
```
