# T1.5 — Enhance Parser

## Goal
Update the parser to produce the enriched AST types from T1.3: parse implied amounts,
extract tags and unique IDs from comments, handle status markers, and support the full
hledger transaction format.

## Context
The current parser (`parser/parser.go`) handles the basic transaction format but cannot
parse implied amounts (where one posting omits the amount), tags, unique IDs, or status
markers. These are required for hledger compatibility.

**Depends on:** T1.3 (AST types), T1.4 (enhanced lexer)
**Blocks:** T1.7 (interpreter), T1.8+ (CLI commands)

---

## Changes to `parser/parser.go`

### 1. Parse transaction status markers
After parsing the date token, check for `TOKEN_STATUS`:
```
DATE [STATUS] STRING(description) NEWLINE
```
Store the status character in `Transaction.Status`.

If no `TOKEN_STATUS` is present, `Transaction.Status = ""`.

### 2. Parse transaction-level comments and tags
After the transaction header line, before the first indented posting, there may be
comment lines (lines starting with `;`). Parse these and:

- Look for `; id: <value>` → store in `Transaction.ID`
- Look for `; key: value` (any key-value pair) → store in `Transaction.Tags`
- Any other comment text → append to `Transaction.Comment`

Helper function:
```go
func parseTagsFromComment(commentLiteral string) (id string, tags map[string]string, rest string)
```

The `commentLiteral` is the full `TOKEN_COMMENT` literal including the `;` prefix.
Strip the `;` and optional leading space, then:
- If the text matches `id: <value>` → extract ID
- If the text matches `<key>: <value>` where key is a single word → extract tag
- Otherwise → treat as plain comment text

### 3. Parse implied (omitted) amounts
A posting line may omit the amount:
```
    assets:checking        ; <- no amount here
```

Currently the parser requires an amount. Change to:
- After parsing `TOKEN_INDENT` + `TOKEN_ACCOUNT`:
  - If the next meaningful token (skipping whitespace) is `TOKEN_NEWLINE`, `TOKEN_COMMENT`,
    or `TOKEN_EOF` → create a posting with `AmountOmitted = true`
  - Otherwise → parse the amount as before

Validation in the parser (or during `FillImpliedAmounts`): at most one posting per
transaction may have `AmountOmitted = true`. Emit a parse error if more than one posting
is omitted.

After parsing all postings of a transaction, call `transaction.FillImpliedAmounts()` to
compute the implied amount and set it on the posting.

### 4. Parse inline posting comments and tags
After the amount on a posting line, there may be an inline comment:
```
    expenses:groceries    $45.32  ; food:groceries category:food
```

Parse the `TOKEN_COMMENT` on posting lines and extract tags using the same
`parseTagsFromComment` helper. Store in `Posting.Tags` and `Posting.Comment`.

### 5. Handle blank lines and standalone comments between transactions
In the main `ParseTransactions` loop, when at the top level (between transactions):
- `TOKEN_NEWLINE` → skip (blank line)
- `TOKEN_COMMENT` → skip (standalone comment, not attached to any transaction)
- `TOKEN_DATE` → start a new transaction
- `TOKEN_EOF` → done

Currently this logic may not handle all these cases. Fix the loop to be explicit.

### 6. Stricter balance validation with implied amounts
After `FillImpliedAmounts()`:
- Call `IsBalanced()` on the completed transaction
- If not balanced, return a descriptive error: `"transaction on DATE 'DESCRIPTION' is unbalanced: sum is X"`

### 7. Add parser tests (`parser/parser_test.go`)

```go
package parser

import (
    "testing"
    "doublebook/ast"
)

func TestBasicTransaction(t *testing.T) {
    input := `2025-01-15 Grocery Store
    expenses:groceries    $45.32
    assets:checking      -$45.32
`
    txns, err := ParseTransactions(input)
    if err != nil { t.Fatal(err) }
    if len(txns) != 1 { t.Fatalf("expected 1 transaction, got %d", len(txns)) }
    txn := txns[0]
    if txn.Date != "2025-01-15" { t.Errorf("wrong date: %s", txn.Date) }
    if txn.Description != "Grocery Store" { t.Errorf("wrong desc: %s", txn.Description) }
    if len(txn.Postings) != 2 { t.Fatalf("expected 2 postings, got %d", len(txn.Postings)) }
}

func TestImpliedAmount(t *testing.T) {
    input := `2025-01-15 Grocery Store
    expenses:groceries    $45.32
    assets:checking
`
    txns, err := ParseTransactions(input)
    if err != nil { t.Fatal(err) }
    if len(txns) != 1 { t.Fatal("expected 1 transaction") }
    posting := txns[0].Postings[1]
    if posting.AmountOmitted { t.Error("AmountOmitted should be false after FillImpliedAmounts") }
    if posting.Amount.Value != -45.32 { t.Errorf("implied amount wrong: %f", posting.Amount.Value) }
}

func TestTransactionWithTags(t *testing.T) {
    input := `2025-01-15 Grocery Store
    ; category: food
    ; id: abc123
    expenses:groceries    $45.32
    assets:checking      -$45.32
`
    txns, err := ParseTransactions(input)
    if err != nil { t.Fatal(err) }
    txn := txns[0]
    if txn.ID != "abc123" { t.Errorf("wrong ID: %s", txn.ID) }
    if txn.Tags["category"] != "food" { t.Errorf("wrong tag: %v", txn.Tags) }
}

func TestStatusMarker(t *testing.T) {
    input := `2025-01-15 * Cleared
    expenses:food    $10.00
    assets:cash     -$10.00
`
    txns, err := ParseTransactions(input)
    if err != nil { t.Fatal(err) }
    if txns[0].Status != "*" { t.Errorf("wrong status: %s", txns[0].Status) }
}

func TestCommentBetweenTransactions(t *testing.T) {
    input := `2025-01-15 First
    expenses:food    $10.00
    assets:cash     -$10.00

; This comment is between transactions

2025-01-16 Second
    expenses:food    $5.00
    assets:cash     -$5.00
`
    txns, err := ParseTransactions(input)
    if err != nil { t.Fatal(err) }
    if len(txns) != 2 { t.Fatalf("expected 2 transactions, got %d", len(txns)) }
}

func TestMultipleCurrencies(t *testing.T) {
    input := `2025-01-15 Foreign Purchase
    expenses:travel    100 BGN
    assets:checking   -100 BGN
`
    txns, err := ParseTransactions(input)
    if err != nil { t.Fatal(err) }
    if txns[0].Postings[0].Amount.Currency != "BGN" {
        t.Errorf("expected BGN, got %s", txns[0].Postings[0].Amount.Currency)
    }
}
```
