# T4.2 — REST API Server

## Goal

Implement the `doublebook api` command that starts a REST API server on port 5555,
bridging the web interface and external integrations to the core DoubleBook engine.
The API must only expose existing functionality — no new business logic.

## Context

The API is the single source of truth for the web interface and any external tools.
It uses Go's standard `net/http` package (no heavy framework). All responses are JSON.

**Depends on:** T1.7 (interpreter), T3.1 (SQLite/FQL), T4.1 (currency)
**Blocks:** T4.3 (web UI calls this API)

---

## Create `api/server.go`

```go
package api

import (
    "net/http"
    "encoding/json"
)

// Server holds the API server state.
type Server struct {
    port        int
    interpreter *interpreter.Interpreter
    db          *db.DB
    converter   *currency.CachingConverter
    mux         *http.ServeMux
}

// NewServer creates a new API server.
func NewServer(port int, interp *interpreter.Interpreter, db *db.DB, conv *currency.CachingConverter) *Server

// Start starts the HTTP server. Blocks until stopped.
func (s *Server) Start() error

// Handler returns the http.Handler for use with the web server.
func (s *Server) Handler() http.Handler
```

### Middleware

Create `api/middleware.go`:

```go
// CORS middleware — allows requests from localhost:4444 (the web UI)
func CORSMiddleware(next http.Handler) http.Handler

// JSON middleware — sets Content-Type: application/json on all responses
func JSONMiddleware(next http.Handler) http.Handler

// Logger middleware — logs method, path, status code, duration
func LoggerMiddleware(next http.Handler) http.Handler

// Recovery middleware — catches panics and returns 500
func RecoveryMiddleware(next http.Handler) http.Handler
```

```go
// respond writes a JSON response with the given status code.
func respond(w http.ResponseWriter, status int, data interface{})

// respondError writes a JSON error response.
```

## Create `api/handlers/` — Route Handlers

### `api/handlers/transactions.go`

```
GET  /api/transactions
     Query params: ?begin=DATE&end=DATE&account=ACCT&limit=N&offset=N
     Returns: { "transactions": [...], "total": N }

GET  /api/transactions/:id
     Returns: { "transaction": {...} }
```

Transaction JSON shape:

```json
{
  "id": "abc123",
  "date": "2025-01-15",
  "description": "Grocery Store",
  "status": "",
  "postings": [
    {
      "account": "expenses:groceries",
      "amount": 45.32,
      "currency": "USD"
    },
    {
      "account": "assets:checking",
      "amount": -45.32,
      "currency": "USD"
    }
  ],
  "tags": { "category": "food" }
}
```

```
GET  /api/accounts
```

## Route registration in `server.go`

```go
func (s *Server) registerRoutes() {
    s.mux.Handle("/api/transactions",           chain(handlers.ListTransactions(s.interpreter), ...))
    s.mux.Handle("/api/transactions/",          chain(handlers.GetTransaction(s.interpreter), ...))
    s.mux.Handle("/api/accounts",               chain(handlers.ListAccounts(s.interpreter), ...))
    s.mux.Handle("/api/reports/balance",        chain(handlers.BalanceReport(s.interpreter), ...))
    s.mux.Handle("/api/reports/income-statement", chain(handlers.IncomeStatement(s.interpreter), ...))
    s.mux.Handle("/api/fql",                    chain(handlers.FQLQuery(s.db), ...))
    s.mux.Handle("/api/import",                 chain(handlers.ImportCSV(s.interpreter), ...))
    s.mux.Handle("/api/exchange-rates",         chain(handlers.ExchangeRate(s.converter), ...))
}

func chain(h http.HandlerFunc, middleware ...func(http.Handler) http.Handler) http.Handler
```

## Acceptance Criteria

- [ ] `go build ./...` succeeds
- [ ] `./doublebook api` starts the server and prints the URL
- [ ] `curl http://localhost:5555/api/transactions` returns JSON
- [ ] `curl http://localhost:5555/api/accounts` returns JSON
- [ ] `curl http://localhost:5555/api/reports/balance` returns JSON
- [ ] `curl -X POST -d '{"query":"SELECT account FROM accounts"}' http://localhost:5555/api/fql` returns JSON
- [ ] CORS headers are set (for web UI on port 4444)
- [ ] Invalid routes return 404 JSON
- [ ] Panics return 500 JSON (not crash the server)
- [ ] `./doublebook api --port 8080` uses port 8080

## Verification Commands

```bash
go build ./...
go build -o doublebook .
./doublebook api &
curl http://localhost:5555/api/transactions
curl http://localhost:5555/api/accounts
curl -X POST -H "Content-Type: application/json" \
  -d '{"query":"SELECT account, SUM(amount) AS total FROM accounts ORDER BY total DESC"}' \
  http://localhost:5555/api/fql
kill %1  # stop the server
```
