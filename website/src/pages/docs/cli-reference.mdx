# CLI Reference

Complete reference for all DoubleBook commands and options.

## Global Flags

These flags work with all commands:

| Flag | Description |
|------|-------------|
| `--journal NAME` | Use journal stem NAME (default: "data") |
| `--begin DATE` | Filter: only transactions on/after DATE |
| `--end DATE` | Filter: only transactions on/before DATE |
| `--verbose` | Enable verbose output |
| `--help` | Show help message |

```bash
# Examples
doublebook --journal personal balance
doublebook --begin 2025-01-01 --end 2025-01-31 register
doublebook --verbose balance
```

## Commands

### balance, bal

Show account balances.

```bash
doublebook balance [flags]
```

| Flag | Description |
|------|-------------|
| `--tree` | Display as hierarchical tree |
| `--flat` | Display as flat list (default) |
| `--account PATTERN` | Filter by account name |
| `--depth N` | Limit account depth in output |

```bash
# Basic balance
doublebook balance

# Tree view
doublebook balance --tree

# Filter by account
doublebook balance --account expenses

# Limit depth
doublebook balance --tree --depth 2
```

### register, reg, r

Show transaction register with running totals.

```bash
doublebook register [flags]
```

| Flag | Description |
|------|-------------|
| `--account PATTERN` | Filter by account name |
| `--limit N` | Limit number of results |
| `--offset N` | Skip first N results |

```bash
# All transactions
doublebook register

# Filter by account
doublebook register --account expenses:food

# Paginate results
doublebook register --limit 20 --offset 40
```

### list, ls

Alias for register command.

```bash
doublebook list
doublebook ls --account assets
```

### is, income-statement

Show income statement (revenues vs expenses).

```bash
doublebook income-statement [flags]
```

```bash
# Current period income statement
doublebook is

# Specific period
doublebook --begin 2025-01-01 --end 2025-03-31 is
```

### add, insert

Add a new transaction interactively or via flags.

```bash
doublebook add [flags]
```

| Flag | Description |
|------|-------------|
| `--date DATE` | Transaction date (YYYY-MM-DD) |
| `--description TEXT` | Transaction description |
| `--amount N` | Amount to transfer |
| `--from ACCOUNT` | Source account |
| `--to ACCOUNT` | Destination account |
| `--cleared` | Mark as cleared (*) |

```bash
# Interactive mode
doublebook add

# With all flags
doublebook add \
  --date 2025-01-15 \
  --description "Coffee Shop" \
  --amount 4.50 \
  --from assets:checking \
  --to expenses:dining \
  --cleared
```

### fql, query

Financial Query Language - SQL-like queries.

```bash
doublebook fql [flags]
```

| Flag | Description |
|------|-------------|
| `--query "SQL"` | Run a single query |
| (no flags) | Start interactive REPL |

```bash
# Interactive REPL
doublebook fql

# Single query
doublebook fql --query "SELECT * FROM transactions LIMIT 10"

# Complex query
doublebook fql --query "
  SELECT account, SUM(amount) AS total
  FROM transactions
  WHERE account LIKE 'expenses:%'
  GROUP BY account
  ORDER BY total DESC
"
```

### map, mapper

Interactive column mapper for creating import rules.

```bash
doublebook map [flags] <file>
```

| Flag | Description |
|------|-------------|
| `--output PATH` | Custom output path for rules file |
| `--list` | List existing rules |
| `--show NAME` | Show details of a rule |

```bash
# Interactive mapping
doublebook map statement.csv
doublebook map statement.xlsx

# List existing rules
doublebook map --list

# Show rule details
doublebook map --show my-bank
```

### import

Import transactions from CSV/Excel files.

```bash
doublebook import [flags] <file>
```

| Flag | Description |
|------|-------------|
| `--rules NAME` | Rules file name or path (recommended) |
| `--map PATH` | Legacy importmap.json file |
| `--dry-run` | Preview without writing |
| `--verbose` | Show each imported transaction |

```bash
# Import with rules (recommended)
doublebook import --rules my-bank statement.csv --dry-run
doublebook import --rules my-bank statement.csv

# Legacy import
doublebook import --map bank.importmap.json statement.csv
```

### plugin

Manage and run plugins.

```bash
doublebook plugin <subcommand> [flags]
```

#### Subcommands

| Subcommand | Description |
|------------|-------------|
| `list` | List installed plugins |
| `run NAME` | Run a plugin command |

```bash
# List plugins
doublebook plugin list

# Run plugin
doublebook plugin run sql-export --output ~/finance.db
doublebook plugin run recurring status
doublebook plugin run recurring list
doublebook plugin run recurring generate
```

### api

Start REST API server.

```bash
doublebook api [flags]
```

| Flag | Description |
|------|-------------|
| `--port N` | Port to listen on (default: 5555) |
| `--host ADDR` | Host address (default: localhost) |

```bash
# Start on default port
doublebook api

# Custom port
doublebook api --port 8080

# Listen on all interfaces
doublebook api --host 0.0.0.0 --port 5555
```

### web

Start web UI server.

```bash
doublebook web [flags]
```

| Flag | Description |
|------|-------------|
| `--port N` | Port to listen on (default: 8080) |

```bash
doublebook web
doublebook web --port 3000
```

### reset

Delete all journal data. Useful for testing or starting fresh.

```bash
doublebook reset [flags]
```

| Flag | Description |
|------|-------------|
| `--force` | Skip confirmation prompt |
| `--dry-run` | Show what would be deleted without deleting |

```bash
# Preview what will be deleted
doublebook reset --dry-run

# Interactive reset (asks for confirmation)
doublebook reset

# Force reset without confirmation (for scripts)
doublebook reset --force

# Reset a specific journal
doublebook --journal test reset --force
```

**Warning:** This permanently deletes all journal files. The `--dry-run` flag lets you preview what will be deleted before committing.

### help

Show help message.

```bash
doublebook help
doublebook help balance
doublebook help fql
```

### version

Show version information.

```bash
doublebook version
```

## Usage Examples

### Daily Workflow

```bash
# Check current balances
doublebook balance

# Add today's transactions
doublebook add

# Review recent activity
doublebook register --limit 10
```

### Monthly Review

```bash
# This month's transactions
doublebook --begin 2025-01-01 --end 2025-01-31 register

# Income statement
doublebook --begin 2025-01-01 --end 2025-01-31 is

# Expense breakdown
doublebook fql --query "
  SELECT account, SUM(amount) AS total
  FROM transactions
  WHERE account LIKE 'expenses:%'
    AND date >= '2025-01-01'
  GROUP BY account
  ORDER BY total DESC
"
```

### Data Management

```bash
# Import bank statement
doublebook import --file ~/Downloads/statement.csv --map bank.yaml

# Export to SQLite
doublebook plugin run sql-export --output ~/finance.db

# Check recurring payments
doublebook plugin run recurring status

# Reset all data (start fresh)
doublebook reset --dry-run   # preview first
doublebook reset             # requires typing 'yes'
```
