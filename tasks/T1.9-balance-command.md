# T1.9 — CLI `balance` Command

## Goal

Implement the `doublebook balance` command that shows account balances, supporting
flat and tree display modes, date filtering, and currency-aware formatting.

## Context

The balance report is the most fundamental output of any accounting tool.
The interpreter already has the calculation logic (from T1.7); this task wires
it up to the CLI with proper formatting.

**Depends on:** T1.7 (interpreter), T1.8 (config/context)
**Blocks:** nothing (standalone command)

---

## Create `cli/commands/balance_command.go`

### Command signature

```
doublebook balance [flags]

Flags:
  --tree          Show as account hierarchy (default: flat list)
  --begin DATE    Only include transactions on or after this date
  --end DATE      Only include transactions before or on this date
  --account ACCT  Only show accounts matching this pattern
  --no-total      Do not print the grand total line
```

### Implementation

```go
package commands

import (
    "fmt"
    "sort"
    "strings"
    "doublebook/cli"
    "doublebook/interpreter"
)

func RunBalanceCommand(ctx *cli.Context, args []string) error
```

Parse flags from `args`:

- `--tree` → set `treeMode = true`
- `--begin DATE` → set filter begin date
- `--end DATE` → set filter end date
- `--account ACCT` → set filter account
- `--no-total` → omit total line

Load journal using `ctx.JournalName` and the `journal` package.

Build filter from flags + context (context may already have `BeginDate`/`EndDate`).

#### Flat mode output

When `--tree` is NOT set, output a simple sorted list:

```
          $1,635.50  assets:checking
         $-1,000.00  equity
             $64.50  expenses:groceries
            $800.00  expenses:rent
          $-1,500.00  income:consulting
─────────────────────────────────────
                 $0
```

Rules:

- Sort accounts alphabetically
- Right-align amounts in a consistent column width
- Print a separator line and the net total at the bottom
- Total should be 0 for balanced journals

#### Tree mode output

When `--tree` IS set, show hierarchy:

```
          $1,635.50  assets
          $1,635.50    checking
         $-1,000.00  equity
            $864.50  expenses
             $64.50    groceries
            $800.00    rent
          $-1,500.00  income
          $-1,500.00    consulting
─────────────────────────────────
                 $0
```

Rules:

- Each level of nesting is indented by 2 spaces
- Parent nodes show the sum of all their children
- Leaf nodes show the actual amount
- Same right-aligned amount column

#### Amount formatting

- USD: `$1,234.56` or `$-1,234.56`
- GBP: `£1,234.56`
- EUR: `€1,234.56`
- Other: `1,234.56 BGN`
- Right-align in a field wide enough for all amounts

Use a two-pass approach: first collect all amounts, find the maximum width, then print
with consistent right-alignment.

#### Zero balances

By default, omit accounts with zero balance. This matches hledger behavior.
