# T5.1 — Enhanced Plugin Interface and Manager

## Goal
Enhance the plugin system with a richer interface, proper lifecycle management,
and configuration-based plugin loading. The interface should be stable enough
for third-party plugin authors to build against.

## Context
The existing plugin system is a skeleton. We need to make it production-ready
before building the two built-in plugins on top of it.

**Depends on:** T1.7 (interpreter uses plugins), T2.3 (import — new OnImport hook)
**Blocks:** T5.2 (SQL export plugin), T5.3 (recurring plugin)

## Update `plugin/plugin.go`

### Enhanced interface

```go
package plugin

import (
    "doublebook/ast"
    "doublebook/interpreter"
)

// Plugin is the interface that all DoubleBook plugins must implement.
type Plugin interface {
    // Name returns the unique identifier for this plugin.
    Name() string

    // Version returns the plugin version string.
    Version() string

    // Description returns a human-readable description.
    Description() string

    // Initialize is called once when the plugin is loaded.
    // config is the plugin-specific config from the config file.
    Initialize(config map[string]interface{}) error

    // Shutdown is called when DoubleBook exits cleanly.
    Shutdown() error

    // Hooks — all hooks are optional (embed DefaultPlugin for no-op defaults)
    OnParse(transactions []*ast.Transaction) error
    OnAdd(transaction *ast.Transaction) error
    OnFilter(transactions []*ast.Transaction, filter interpreter.Filter) []*ast.Transaction
    OnReport(transactions []*ast.Transaction) string
    OnImport(rows []ImportRow, importMapName string) error
}

// ImportRow represents a single row passed to OnImport.
type ImportRow struct {
    Date        string
    Description string
    Amount      float64
    Currency    string
    Account     string
    Reference   string
}

// DefaultPlugin provides no-op implementations of all optional hooks.
// Embed this in your plugin to avoid implementing every method.
type DefaultPlugin struct{}

func (d *DefaultPlugin) OnParse(_ []*ast.Transaction) error      { return nil }
func (d *DefaultPlugin) OnAdd(_ *ast.Transaction) error           { return nil }
func (d *DefaultPlugin) OnFilter(txns []*ast.Transaction, _ interpreter.Filter) []*ast.Transaction {
    return txns
}
func (d *DefaultPlugin) OnReport(_ []*ast.Transaction) string     { return "" }
func (d *DefaultPlugin) OnImport(_ []ImportRow, _ string) error   { return nil }
func (d *DefaultPlugin) Shutdown() error                          { return nil }
```

## Update `plugin/manager.go`

### PluginManager

```go
// PluginManager manages the lifecycle of all loaded plugins.
type PluginManager struct {
    plugins []Plugin
    logger  func(string) // simple log function
}

func NewPluginManager() *PluginManager

// Register adds a plugin and calls Initialize.
func (pm *PluginManager) Register(p Plugin, config map[string]interface{}) error

// Get returns a plugin by name.
func (pm *PluginManager) Get(name string) (Plugin, bool)

// List returns all registered plugin names.
func (pm *PluginManager) List() []string

// ShutdownAll calls Shutdown on all plugins.
func (pm *PluginManager) ShutdownAll() error

// ExecuteOnParse calls OnParse for all plugins.
func (pm *PluginManager) ExecuteOnParse(transactions []*ast.Transaction) error

// ExecuteOnAdd calls OnAdd for all plugins.
func (pm *PluginManager) ExecuteOnAdd(transaction *ast.Transaction) error

// ExecuteOnFilter applies all plugin filters in sequence.
func (pm *PluginManager) ExecuteOnFilter(transactions []*ast.Transaction, filter interpreter.Filter) []*ast.Transaction

// ExecuteOnReport collects OnReport output from all plugins.
func (pm *PluginManager) ExecuteOnReport(transactions []*ast.Transaction) []PluginReport

// ExecuteOnImport calls OnImport for all plugins.
func (pm *PluginManager) ExecuteOnImport(rows []ImportRow, mapName string) error

// PluginReport holds a plugin's report output.
type PluginReport struct {
    PluginName string
    Content    string
}
```

## Add `doublebook plugin` CLI command

### `cli/commands/plugin_command.go`

```go
// doublebook plugin list — shows registered plugins
// doublebook plugin run <name> [args...] — runs a plugin command

func RunPluginCommand(ctx *cli.Context, args []string) error {
    if len(args) == 0 || args[0] == "list" {
        return runPluginList(ctx)
    }
    if args[0] == "run" && len(args) >= 2 {
        return runPlugin(ctx, args[1], args[2:])
    }
    return fmt.Errorf("usage: doublebook plugin [list|run <name>]")
}
```

Plugin run dispatches to plugin-specific subcommands. Each built-in plugin
implements a `RunCommand(args []string) error` method beyond the Plugin interface.
