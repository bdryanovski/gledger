# T3.5 — FQL REPL and `--query` Command

## Goal

Implement the `doublebook fql` interactive REPL (fullscreen Bubbletea) and the
`doublebook fql --query "<fql>"` single-shot query mode.

## Context

The FQL REPL gives users a rich interface to query their financial data. The `--query`
mode enables scripting and piping. Both use the FQL compiler and chart renderer from
previous tasks.

**Depends on:** T3.3 (FQL compiler), T3.4 (chart renderer), T3.1 (SQLite backend)
**Blocks:** nothing (standalone feature)

## Create `ui/fql_repl.go` — Fullscreen FQL REPL

The REPL is a fullscreen Bubbletea program (unlike `insert` which is inline).

### UI layout

```
╔══════════════════════════════════════════════════════╗
║  DoubleBook FQL — Financial Query Language           ║
╚══════════════════════════════════════════════════════╝

Tables: transactions, accounts, spending

[output area — scrollable — shows result of last query]
[output area]
[output area]
─────────────────────────────────────────────────────
FQL> █
[status bar: "Ready" / "Running..." / "Error: ..."]
```

### Model

```go
type FQLModel struct {
    // Input
    input     string
    cursor    int
    history   []string
    histIndex int

    // Output
    output    []string // lines of output
    scrollPos int
    viewport  viewport.Model // bubbletea viewport for scrolling

    // DB connection
    db       *db.DB

    // Terminal dimensions
    width    int
    height   int

    // State
    status   string // "ready", "running", "error"
    quitting bool
}
```

### Key bindings

| Key                            | Action                           |
| ------------------------------ | -------------------------------- |
| `Enter`                        | Execute the current query        |
| `↑` / `Ctrl+P`                 | Previous history entry           |
| `↓` / `Ctrl+N`                 | Next history entry               |
| `Page Up` / `k`                | Scroll output up                 |
| `Page Down` / `j`              | Scroll output down               |
| `Ctrl+L`                       | Clear output                     |
| `Ctrl+C` / `q` (on empty line) | Quit REPL                        |
| `Tab`                          | Auto-complete table/column names |
| `Ctrl+A`                       | Move cursor to beginning of line |
| `Ctrl+E`                       | Move cursor to end of line       |

### Tab completion

When user presses Tab:

1. Get the word at the cursor
2. Check if it could be a table name → suggest from `fql.Tables` keys
3. If after a `.` → suggest columns of the preceding table name
4. If after `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY` keywords → suggest columns of the FROM table (if FROM has been typed)
5. Display suggestions inline (show first match, cycle through on repeated Tab)

### Output rendering

When a query executes:

1. Show the FQL query in a dim/muted color: `FQL> SELECT ...`
2. Show the output (table or chart) from `fql.Execute`
3. Show execution time: `(3.2ms)`
4. Add to history
5. Scroll to bottom of output

### Welcome message

On startup, print:

```
╔══════════════════════════════════════════════════════╗
║  FQL — Financial Query Language                      ║
╚══════════════════════════════════════════════════════╝

Available tables:
  transactions  - all journal postings
  accounts      - account summaries and balances
  spending      - aggregated spending by date and account

Type a query and press Enter. Use ↑/↓ for history. q to quit.

Example: SELECT account, SUM(amount) AS total FROM accounts ORDER BY total ASC
```

## Create `cli/commands/fql_command.go`

### `--query` mode

When `--query` flag is provided:

1. Initialize the DB (load journal → SQLite)
2. Compile and execute the FQL query
3. Print the output to stdout
4. Exit

```go
func RunFQLCommand(ctx *cli.Context, args []string) error {
    // Parse --query flag
    query, remaining := parseQueryFlag(args)

    // Initialize DB
    db, err := initDB(ctx)
    if err != nil { return err }
    defer db.Close()

    if query != "" {
        // Single-shot mode
        width := getTerminalWidth() // default 80 if not a TTY
        output, err := fql.Execute(query, db, width)
        if err != nil {
            fmt.Fprintln(os.Stderr, "Error:", err)
            return err
        }
        fmt.Println(output)
        return nil
    }

    // REPL mode
    model := ui.NewFQLModel(db, getTerminalWidth(), getTerminalHeight())
    program := tea.NewProgram(model, tea.WithAltScreen())
    _, err = program.Run()
    return err
}
```

### Helper: `getTerminalWidth`

```go
import "golang.org/x/term"

func getTerminalWidth() int {
    width, _, err := term.GetSize(int(os.Stdout.Fd()))
    if err != nil { return 80 }
    return width
}
```
