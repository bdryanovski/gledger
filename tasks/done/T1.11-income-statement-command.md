# T1.11 — CLI `is` (Income Statement) Command

## Goal

Implement the `doublebook is` command that generates an income statement comparing
revenues vs expenses, with support for period grouping (daily, weekly, monthly),
pretty box-drawing table output, row totals, and averages.

## Context

The income statement is the third core report. It answers "did I make or lose money?"
for a given period. The example in the spec shows a rich table with daily columns,
totals, and averages — that full table is the target output for `--pretty` mode.

**Depends on:** T1.7 (interpreter, IncomeStatement), T1.8 (config/context)
**Blocks:** nothing (standalone command)

## Create `cli/commands/is_command.go`

### Command signature

```
doublebook is [flags]

Aliases: income-statement, income

Flags:
  --begin DATE    Start date (inclusive)
  --end DATE      End date (inclusive)
  --daily         Break down by day (default for short ranges)
  --weekly        Break down by week
  --monthly       Break down by month (default for longer ranges)
  --yearly        Break down by year
  --tree          Show account hierarchy
  --pretty        Use box-drawing characters for table borders
  --row-total     Add a Total column
  --average       Add an Average column
  --no-total      Omit the grand total row
```

#### Box-drawing table implementation

Create a helper in this file (or in `utils/`) for rendering box-drawing tables:

```go
type TableRenderer struct {
    Headers     []string     // column headers
    Rows        [][]string   // data rows
    DoubleLeft  bool         // use ║ for the left separator (account | data)
    SectionRows []int        // row indices that get double-line separators
}

func (r *TableRenderer) Render() string
```

Unicode box-drawing characters to use:

```
─ ─ │ │ ┼ ┬ ┴ ┤ ├ ┐ ┘ └ ┌   (single)
═ ║ ╬ ╦ ╩ ╣ ╠ ╗ ╝ ╚ ╔       (double)
╪ ╫ ╞ ╡ ╥ ╨                  (mixed)
```

#### Period grouping

When `--daily`, `--weekly`, or `--monthly` is set:

1. Determine the set of period labels (dates, week numbers, or months)
2. For each period, calculate revenue and expense totals
3. Each period becomes a column in the pretty table

Period detection: if `--begin` and `--end` span more than 62 days and no period flag
is given, default to `--monthly`. If 8–62 days, default to `--daily`. Otherwise `--daily`.
