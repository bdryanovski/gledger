# T2.2 — importmap.json Format and Parser

## Goal

Define and implement the `importmap.json` format that describes how to parse and
map columns from a CSV bank export file to DoubleBook journal entries. Create the
parser for this format.

## Context

Different banks export CSV files in different formats, delimiters, encodings, and
column layouts. The importmap is a configuration file that bridges any bank CSV
to the DoubleBook format. This task defines the format and builds the parser.
The actual CSV processing happens in T2.3.

**Depends on:** T1.8 (config structure for reference)
**Blocks:** T2.3 (CSV importer uses importmaps)

## Create `importer/importmap.go`

### ImportMap struct

```go
package importer

// ImportMap describes how to parse a specific bank's CSV export format.
type ImportMap struct {
    Name           string            `json:"name"`            // human-readable name, e.g. "my-bank"
    Delimiter      string            `json:"delimiter"`       // field delimiter, default ","
    Encoding       string            `json:"encoding"`        // source encoding, default "utf-8"
    SkipLines      int               `json:"skip_lines"`      // number of header lines to skip, default 1
    DateFormat     string            `json:"date_format"`     // Go time format string, e.g. "02/01/2006"
    TimeColumn     *int              `json:"time_column"`     // optional: column index for time
    TimeFormat     string            `json:"time_format"`     // Go time format for time, e.g. "15:04"
    Columns        ColumnMap         `json:"columns"`         // column mappings
    SourceAccount  string            `json:"source_account"`  // the account this CSV is for (e.g. "assets:checking:mybank")
    DefaultDebitAccount  string      `json:"default_debit_account"`  // where debit goes (e.g. "expenses:unknown")
    DefaultCreditAccount string      `json:"default_credit_account"` // where credit goes (e.g. "income:unknown")
    Currency       string            `json:"currency"`        // default currency if not in CSV
    Transforms     []Transform       `json:"transforms"`      // optional post-processing rules
}

// ColumnMap defines which CSV column index (0-based) maps to which field.
// Use -1 to indicate "not present in this CSV".
type ColumnMap struct {
    Date            int    `json:"date"`             // required: column index for date
    DebitAmount     int    `json:"debit_amount"`      // column for debit (expense) amount
    CreditAmount    int    `json:"credit_amount"`     // column for credit (income) amount
    Amount          int    `json:"amount"`            // alternative: single amount column (positive=credit, negative=debit)
    Description     int    `json:"description"`       // merchant/description column
    Reference       int    `json:"reference"`         // unique reference/transaction ID from bank
    Currency        int    `json:"currency"`          // optional: column for currency code
    Category        int    `json:"category"`          // optional: bank's own category
    Balance         int    `json:"balance"`           // optional: running balance (ignored, for reference)
}

// Transform is a rule that modifies parsed data based on matching conditions.
// Used to auto-categorize transactions.
type Transform struct {
    // Match conditions (all must match if multiple specified)
    DescriptionContains string `json:"description_contains"`
    AmountMin           *float64 `json:"amount_min"`
    AmountMax           *float64 `json:"amount_max"`

    // Overrides to apply when matched
    DebitAccount  string            `json:"debit_account"`   // override default debit account
    CreditAccount string            `json:"credit_account"`  // override default credit account
    Tags          map[string]string `json:"tags"`            // tags to attach
    Category      string            `json:"category"`        // category tag to attach
}
```

### `LoadImportMap` function

```go
// LoadImportMap reads and validates an importmap.json file.
func LoadImportMap(path string) (*ImportMap, error)
```

Implementation:

1. Read file at `path`
2. Unmarshal JSON into `ImportMap`
3. Validate required fields:
   - `columns.date` must be set (≥ 0)
   - Either `columns.amount` OR (`columns.debit_amount` AND `columns.credit_amount`) must be set
   - `source_account` must be non-empty
4. Apply defaults:
   - `Delimiter` = `","` if empty
   - `Encoding` = `"utf-8"` if empty
   - `SkipLines` = `1` if zero
   - `DateFormat` = `"2006-01-02"` if empty
   - `DefaultDebitAccount` = `"expenses:unknown"` if empty
   - `DefaultCreditAccount` = `"income:unknown"` if empty
5. Return validated `*ImportMap`

## Create sample importmap for the Bulgarian bank CSV

Create `sample/sample.importmap.json` based on the structure of `sample/sample.csv`:

The sample CSV is pipe-delimited with these columns (0-indexed):

```
0:  date (format: DD/MM/YYYY)
1:  time (HH:MM)
2:  debit_amount (BGN amount spent)
3:  debit_eur (EUR equivalent)
4:  credit_amount (BGN amount received)
5:  credit_eur (EUR equivalent)
6:  type (Cyrillic text, payment type)
7:  description (merchant name, sometimes Cyrillic)
8:  balance (BGN running balance)
9:  balance_eur
10: reference (bank's transaction reference)
11: description2 (additional description)
12: another_ref
... (more columns we can ignore)
```

{
  "name": "sample-bulgarian-bank",

  "columns": {
    "date": 0,
