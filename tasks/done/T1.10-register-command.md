# T1.10 — CLI `register` Command

## Goal

Implement the `doublebook register` command that shows a running transaction register —
a chronological list of transactions with their postings and a running balance.

## Context

The register view is the second most important output. It shows what happened when,
and gives a running total so you can reconcile with bank statements.

**Depends on:** T1.7 (interpreter with filters), T1.8 (config/context)
**Blocks:** nothing (standalone command)

---

## Create `cli/commands/register_command.go`

### Command signature

```
doublebook register [flags]

Aliases: reg, r

Flags:
  --begin DATE    Only include transactions on or after this date
  --end DATE      Only include transactions before or on this date
  --account ACCT  Only show transactions involving this account pattern
  --desc TEXT     Only show transactions where description contains TEXT
  --limit N       Show only the last N transactions
```

### Output format

Match hledger `register` output style:

```
2025-01-15 Grocery Store        expenses:groceries         $45.32        $45.32
                                assets:checking           -$45.32             0
2025-01-16 Salary Payment       assets:checking         $2,000.00     $2,000.00
                                income:salary           -$2,000.00             0
2025-01-18 Electric Bill        expenses:utilities         $89.50        $89.50
                                assets:checking           -$89.50             0
```

Columns:

1. Date (YYYY-MM-DD) — only on first posting of each transaction, blank for subsequent
2. Description — only on first posting, blank for subsequent; max 25 chars, truncate with `…`
3. Account — left-aligned; max 30 chars
4. Amount — right-aligned in 12-char field
5. Running total — right-aligned in 12-char field

The running total accumulates across all postings shown.

**Implementation detail:** When `--account` is set, only show the postings that match
the account filter. The running total applies only to those postings.

### Column widths

Define constants at the top of the file:

```go
const (
    colDate    = 10
    colDesc    = 25
    colAccount = 30
    colAmount  = 12
    colRunning = 12
)
```

Use `fmt.Sprintf` with padding to format each column.

### `--limit` flag

When set, take only the last N transactions from the filtered list (not the first N).
This matches hledger behavior where `register --limit 10` shows the most recent 10.

### Color output

Use lipgloss for subtle styling:

- Date: muted/dim
- Description: normal weight
- Account: cyan/blue
- Amount: green if positive, red if negative
- Running total: bold

Make colors optional (disabled if terminal doesn't support color, detected via
`os.Getenv("NO_COLOR")` or checking if stdout is a TTY).
