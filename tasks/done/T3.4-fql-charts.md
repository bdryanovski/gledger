# T3.4 — FQL Terminal Charts

## Goal
Implement terminal chart rendering (bar charts and line charts) for FQL query results,
so users can visualize spending patterns, income trends, and account distributions
directly in the terminal using lipgloss.

## Context
FQL returns rows of data. For certain query shapes (one category column + one numeric
column, or one date column + one numeric column), DoubleBook should automatically or
on-request render a terminal chart instead of a plain table.

**Depends on:** T3.3 (FQL compiler — to know what columns a query produces)
**Blocks:** T3.5 (FQL REPL uses charts)

---

## Create `fql/charts.go`

### Chart types

```go
package fql

// ChartType determines how to visualize query results.
type ChartType int

const (
    ChartNone  ChartType = iota
    ChartBar             // horizontal bar chart (category → amount)
    ChartLine            // line chart (date/time → amount)
)

// ChartResult holds query results ready for chart rendering.
type ChartResult struct {
    Type    ChartType
    Labels  []string  // x-axis labels (categories or dates)
    Values  []float64 // y-axis values (amounts)
    Title   string
}
```

### Chart detection from result columns

```go
// DetectChartType examines query result columns and suggests a chart type.
// Returns ChartNone if no suitable chart type is detected.
//
// Rules:
//   - If there is exactly 1 text column and 1 numeric column → ChartBar
//   - If there is a "date" or "month" column and 1 numeric column → ChartLine
//   - Otherwise → ChartNone
func DetectChartType(columns []string, rows [][]interface{}) ChartType
```

### Bar chart renderer

```go
// RenderBarChart renders a horizontal bar chart using lipgloss.
//
// Example output:
//   expenses:groceries  ████████████████████████ $864.50
//   expenses:rent       ████████████████         $800.00
//   income:consulting   ████                     $500.00
//   expenses:dining     ██                       $200.00
//
// Parameters:
//   result: the chart data
//   width:  terminal width in characters (for scaling bars)
func RenderBarChart(result *ChartResult, width int) string
```

Implementation:
1. Find the maximum absolute value in `result.Values` for scaling
2. Determine max label width for alignment
3. For each label/value pair:
   - Scale value to bar length: `barLen = int((abs(val) / maxVal) * maxBarWidth)`
   - Use `█` (U+2588) for filled sections
   - Use lipgloss colors: green for positive values, red for negative
   - Align: label (left-padded to max label width), bar, formatted value
4. Use `maxBarWidth = width - maxLabelWidth - 15` (leaving room for value column)
5. Cap bars at terminal width

### Line chart renderer

```go
// RenderLineChart renders an ASCII line chart for time-series data.
//
// Example output (simplified braille-dot style):
//
//   2500 ┤                    ╭─────────
//   2000 ┤         ╭──────────╯
//   1500 ┤    ╭────╯
//   1000 ┤╭───╯
//    500 ┼╯
//        └──────────────────────────────
//         Jan   Feb   Mar   Apr   May
//
// Parameters:
//   result: chart data (Labels are dates/months, Values are amounts)
//   width, height: terminal dimensions
func RenderLineChart(result *ChartResult, width, height int) string
```

Implementation (simplified ASCII art approach):
1. Determine y-axis range (min, max of values), create Y bucket rows
2. For each data point, place a character at the appropriate (x, y) cell
3. Connect adjacent points with `─`, `╭`, `╰`, `│` box-drawing chars
4. Add y-axis labels on the left, x-axis labels at the bottom
5. Use a grid of `height` rows × `width` columns

For a simpler first implementation, use a sparkline-style chart:
```
Jan $2000.00  ▂▂▄▄▆▆████▆▄▂▂
Feb $1800.00  ▂▂▄▄▆▆██▆▄▂
Mar $2200.00  ▂▂▄▄▆▆████████▆▄
```

Using Unicode block elements: `▁▂▃▄▅▆▇█` for height levels.

### Table renderer (fallback)

```go
// RenderTable renders query results as a formatted table using lipgloss.
//
// Example:
//   ┌──────────────────┬────────────┬──────────┐
//   │ account          │ date       │ amount   │
//   ├──────────────────┼────────────┼──────────┤
//   │ expenses:food    │ 2025-01-15 │  $45.32  │
//   │ assets:checking  │ 2025-01-15 │ -$45.32  │
//   └──────────────────┴────────────┴──────────┘
func RenderTable(columns []string, rows [][]interface{}, width int) string
```

Implementation using lipgloss table or manual box-drawing:
- Auto-detect column widths from data
- Right-align numeric columns, left-align text columns
- Cap table width at terminal width (truncate long values with `…`)
- Color headers distinctly
