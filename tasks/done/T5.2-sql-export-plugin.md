# T5.2 — SQL Export Plugin

## Goal

Implement the `sql-export` plugin that exports the full journal to a standalone
SQLite database file, idempotently (re-runnable without creating duplicates).
The output file can be used for advanced SQL analysis outside of DoubleBook.

## Context

Some users want to query their journal data with custom SQL tools, Jupyter notebooks,
or BI tools like Metabase. The SQL export plugin creates a standalone SQLite file
with the full journal data.

**Depends on:** T5.1 (plugin interface), T3.1 (SQLite schema)
**Blocks:** nothing

## Create `plugin/extensions/sql_export.go`

### Plugin struct

```go
package extensions

import (
    "doublebook/plugin"
    "doublebook/ast"
    "doublebook/db"
)

// SQLExportPlugin exports the journal to a standalone SQLite file.
type SQLExportPlugin struct {
    plugin.DefaultPlugin
    OutputPath string // set from config or CLI arg
}

func (p *SQLExportPlugin) Name() string        { return "sql-export" }
func (p *SQLExportPlugin) Version() string     { return "1.0.0" }
func (p *SQLExportPlugin) Description() string {
    return "Exports the journal to a standalone SQLite database file"
}

func (p *SQLExportPlugin) Initialize(config map[string]interface{}) error {
    if path, ok := config["output_path"].(string); ok {
        p.OutputPath = path
    }
    return nil
}
```

### `RunCommand` method (plugin-specific CLI)

```go
// RunCommand handles `doublebook plugin run sql-export [--output path]`
func (p *SQLExportPlugin) RunCommand(transactions []*ast.Transaction, args []string) error {
    // Parse --output flag
    outputPath := p.OutputPath
    for i, arg := range args {
        if arg == "--output" && i+1 < len(args) {
            outputPath = args[i+1]
        }
    }
    if outputPath == "" {
        outputPath = "doublebook-export.db"
    }

    fmt.Printf("Exporting to %s...\n", outputPath)

    // Open SQLite at outputPath (not in-memory)
    database, err := db.Open(outputPath)
    if err != nil { return err }
    defer database.Close()

    if err := database.Initialize(); err != nil { return err }

    // Load all transactions
    if err := database.LoadFromTransactions(transactions); err != nil { return err }

    // Create additional views for convenience
    if err := createExportViews(database); err != nil { return err }

    count := len(transactions)
    postingCount := 0
    for _, t := range transactions { postingCount += len(t.Postings) }

    fmt.Printf("Export complete:\n")
    fmt.Printf("  Transactions: %d\n", count)
    fmt.Printf("  Postings:     %d\n", postingCount)
    fmt.Printf("  File:         %s\n", outputPath)
    return nil
}
```

### Additional SQL views for the export

```go
func createExportViews(database *db.DB) error {
    views := `
-- Convenience view: all postings with transaction info
CREATE VIEW IF NOT EXISTS v_register AS
SELECT
    t.date,
    t.description,
    t.status,
    p.account,
    p.amount,
    p.currency,
    t.id AS transaction_id
FROM transactions t
JOIN postings p ON p.transaction_id = t.id
ORDER BY t.date, t.id;

-- Convenience view: account balances
CREATE VIEW IF NOT EXISTS v_balances AS
SELECT
    p.account,
    SUM(p.amount) AS balance,
    p.currency,
    COUNT(*) AS transaction_count
FROM postings p
GROUP BY p.account, p.currency
ORDER BY p.account;

-- Convenience view: monthly spending
CREATE VIEW IF NOT EXISTS v_monthly AS
SELECT
    substr(t.date, 1, 7) AS month,
    p.account,
    SUM(p.amount) AS total,
    COUNT(*) AS count
FROM transactions t
JOIN postings p ON p.transaction_id = t.id
GROUP BY substr(t.date, 1, 7), p.account
ORDER BY month, p.account;
`
    _, err := database.Conn().Exec(views)
    return err
}
```

### OnReport hook (shows export status in normal reports)

```go
// OnReport shows a note if the export is configured.
func (p *SQLExportPlugin) OnReport(_ []*ast.Transaction) string {
    if p.OutputPath == "" { return "" }
    return fmt.Sprintf("SQL Export: run 'doublebook plugin run sql-export' to export to %s", p.OutputPath)
}
```

## Acceptance Criteria

- [ ] `go build ./...` succeeds
- [ ] `./doublebook plugin run sql-export` creates `doublebook-export.db` in the current directory
- [ ] `./doublebook plugin run sql-export --output /tmp/finance.db` uses the specified path
- [ ] Running the command twice does not create duplicate rows
- [ ] The exported database contains all transactions, postings, and tags from the journal

- [ ] Output file can be opened with `sqlite3` and queried
