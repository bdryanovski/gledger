# T1.6 — Journal File Management Package

## Goal

Create the `journal/` package that handles multi-file journal loading (finding and
merging `name.journal`, `name.1.journal`, `name.2.journal`, etc.) and size-based
auto-splitting when a journal file exceeds 1 MB.

## Context

Users can have large journals split across multiple files. The tool must load all parts
transparently. When appending new transactions, if the current file would exceed 1 MB,
a new sequenced file is created automatically.

**Depends on:** T1.5 (parser — needed to parse each journal file)
**Blocks:** T1.7 (interpreter uses this package), T1.8+ (all CLI commands)

## Create `journal/` package

### File: `journal/loader.go`

```go
package journal
```

#### `JournalName` type and resolution logic

```go
// Resolve takes a journal name (e.g., "personal" or "/path/to/personal")
// and returns all existing journal file paths in load order.
//
// Search order:
//   1. If name has an extension (.journal), treat as exact path
//   2. Otherwise try: <name>.journal, <name>.1.journal, <name>.2.journal, ...
//   3. Stop when a numbered file is not found (skip-silent rule)
//
// If name has no directory component, search in the config data directory.
func Resolve(name string, dataDir string) []string
```

**Implementation details:**

- Expand `~/` in paths using `utils.ExpandHome`
- If `name` contains `/` or `\`, treat as absolute/relative path
- If `name` ends in `.journal`, return `[]string{name}` (exact)
- Otherwise: check for `<dataDir>/<name>.journal` first
  - Then `<dataDir>/<name>.1.journal`, `<dataDir>/<name>.2.journal`, ...
  - Stop at the first missing index
- Use `os.Stat` to check file existence

#### `Load` function

```go
// Load loads all journal files for the given name and returns the merged
// list of transactions, sorted by date ascending.
//
// Files are loaded in order; transactions from later files are merged
// with earlier ones. Missing numbered files are silently skipped.
func Load(name string, dataDir string) ([]*ast.Transaction, error)
```

- Calls `Resolve` to get file list
- For each file path, reads the file and calls `parser.ParseTransactions`
- Merges all transaction slices
- Sorts by date (YYYY-MM-DD string comparison is fine since format is consistent)
- Returns merged, sorted slice

#### `LoadFromPath` function

```go
// LoadFromPath loads a single journal file at an exact path.
func LoadFromPath(path string) ([]*ast.Transaction, error)
```

Simple wrapper: read file, parse, return.

### File: `journal/writer.go`

#### Constants

```go
const MaxJournalSize = 1 * 1024 * 1024 // 1 MB
```

#### `AppendTransaction` function

```go
// AppendTransaction appends a single transaction to the appropriate journal file.
//
// If the target file (name.journal) would exceed MaxJournalSize after the append,
// a new file (name.1.journal, name.2.journal, etc.) is created instead.
//
// The transaction is serialized using transaction.String().
func AppendTransaction(name string, dataDir string, txn *ast.Transaction) error
```

**Implementation:**

1. Find the current "active" file (the last existing file in the sequence, or `name.journal` if none)
2. Check its current size with `os.Stat`
3. Serialize the transaction: `txn.String() + "\n"`
4. If `currentSize + len(serialized) > MaxJournalSize`:
   - Find the next available index (e.g., if `name.2.journal` exists, create `name.3.journal`)
   - Create the new file
5. Append the serialized transaction to the target file (open with `O_APPEND|O_WRONLY|O_CREATE`)

#### `WriteAll` function

```go
// WriteAll overwrites the first journal file (name.journal) with all provided
// transactions serialized in order. Used for in-place rewrites (e.g., after sorting).
//
// Does NOT handle size splitting — use for complete rewrites only.
func WriteAll(path string, transactions []*ast.Transaction) error
```

Serialize all transactions using `txn.String()`, join with `\n`, write atomically
(write to temp file, then rename).
