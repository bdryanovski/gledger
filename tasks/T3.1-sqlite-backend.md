# T3.1 — SQLite Backend Layer

## Goal

Create the `db/` package that manages an embedded SQLite database used as a query
cache for FQL. The database is populated from journal data and rebuilt when the
journal changes.

## Context

FQL needs a structured data store to compile queries against. SQLite is used as a
fast, in-process query engine. The journal files are the source of truth; the SQLite
database is a derived, rebuildable cache.

**Depends on:** T1.7 (interpreter/AST for data to load), T1.5 (parser)
**Blocks:** T3.2+ (FQL needs this layer)

## Create `db/schema.go`

Define the SQLite schema:

```go
package db

// Schema contains all CREATE TABLE statements for the DoubleBook database.
const Schema = `
CREATE TABLE IF NOT EXISTS transactions (
    id          TEXT PRIMARY KEY,
    date        TEXT NOT NULL,
    description TEXT NOT NULL,
    status      TEXT DEFAULT '',
    comment     TEXT DEFAULT '',
    created_at  TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS postings (
    id              TEXT PRIMARY KEY,
    transaction_id  TEXT NOT NULL REFERENCES transactions(id),
    account         TEXT NOT NULL,
    amount          REAL NOT NULL,
    currency        TEXT NOT NULL DEFAULT 'USD',
    amount_omitted  INTEGER NOT NULL DEFAULT 0,
    comment         TEXT DEFAULT ''
);

CREATE TABLE IF NOT EXISTS transaction_tags (
    transaction_id  TEXT NOT NULL REFERENCES transactions(id),
    key             TEXT NOT NULL,
    value           TEXT NOT NULL,
    PRIMARY KEY (transaction_id, key)
);

CREATE TABLE IF NOT EXISTS posting_tags (
    posting_id  TEXT NOT NULL REFERENCES postings(id),
    key         TEXT NOT NULL,
    value       TEXT NOT NULL,
    PRIMARY KEY (posting_id, key)
);

CREATE TABLE IF NOT EXISTS exchange_rates (
    date            TEXT NOT NULL,
    from_currency   TEXT NOT NULL,
    to_currency     TEXT NOT NULL,
    rate            REAL NOT NULL,
    PRIMARY KEY (date, from_currency, to_currency)
);

CREATE TABLE IF NOT EXISTS db_meta (
    key     TEXT PRIMARY KEY,
    value   TEXT NOT NULL
);

-- Indexes for common query patterns
CREATE INDEX IF NOT EXISTS idx_postings_account ON postings(account);
CREATE INDEX IF NOT EXISTS idx_postings_date ON transactions(date);
CREATE INDEX IF NOT EXISTS idx_txn_date ON transactions(date);
`
```

## Create `db/db.go`

```go
package db

import (
    "database/sql"
    "fmt"
    "path/filepath"
    "doublebook/ast"
    _ "modernc.org/sqlite"
)

// DB wraps a SQLite database connection.
type DB struct {
    conn     *sql.DB
    path     string
}

// Open opens (or creates) the DoubleBook database at the given path.
// Use ":memory:" for an in-memory database.
func Open(path string) (*DB, error)

// Close closes the database connection.
func (db *DB) Close() error

// Initialize creates tables if they don't exist.
func (db *DB) Initialize() error

// Conn returns the underlying *sql.DB for direct queries.
// Used by the FQL compiler to execute SQL.
func (db *DB) Conn() *sql.DB
```

### `LoadFromTransactions` function

```go
// LoadFromTransactions clears and repopulates the database from a slice of transactions.
// This is the primary way to sync the DB with journal data.
func (db *DB) LoadFromTransactions(transactions []*ast.Transaction) error
```

Implementation:

1. Begin a transaction (`tx.Begin()`)
2. Delete all existing data (DELETE FROM postings; DELETE FROM transaction_tags; etc.)
   or use a simpler approach: DROP and recreate tables
3. For each `*ast.Transaction`:
   - Generate a stable ID: if `txn.ID` is non-empty, use it; otherwise generate from hash of `date+description+first_posting_account+first_posting_amount`
   - INSERT into `transactions`
   - For each posting:
     - Generate posting ID: `txn_id + "_" + strconv.Itoa(index)`
     - INSERT into `postings`
     - For each posting tag, INSERT into `posting_tags`
   - For each transaction tag, INSERT into `transaction_tags`
4. Commit the transaction

### `IsStale` function

```go
// IsStale checks whether the database needs to be rebuilt.
// Compares the stored journal checksum with the current journal checksum.
func (db *DB) IsStale(journalChecksum string) bool

// SetChecksum stores the current journal checksum.
func (db *DB) SetChecksum(checksum string) error
```

The checksum is stored in the `db_meta` table with key `"journal_checksum"`.

### Journal checksum calculation

```go
// ComputeChecksum computes a checksum for a list of journal files.
// Uses the modification times and sizes of all journal files.
func ComputeChecksum(filePaths []string) (string, error)
```

Use SHA256 of all file modification times + sizes concatenated.

### `OpenOrRebuild` function — primary entry point

```go
// OpenOrRebuild opens the database and rebuilds it if the journal has changed.
// This is the main function called at startup.
//
// dbPath: path to the SQLite file (use filepath.Join(dataDir, "cache.db"))
// transactions: all loaded journal transactions
// journalFiles: list of journal file paths (for checksum)
func OpenOrRebuild(dbPath string, transactions []*ast.Transaction, journalFiles []string) (*DB, error)
```

Logic:

1. Open the database at `dbPath`
2. Initialize schema
3. Compute `checksum` from `journalFiles`
4. If `db.IsStale(checksum)`:
   - Call `db.LoadFromTransactions(transactions)`
   - Call `db.SetChecksum(checksum)`
5. Return the DB
