# T1.8 — Config Enhancements

## Goal

Extend the config system to support journal name patterns, base currency, API/web ports,
and the new `~/.doublebook/` default paths. Also add a global flag system for the CLI
so `--journal`, `--begin`, and `--end` can be passed to any command.

## Context

The current config is minimal. As we add features (multi-currency, web, API, FQL),
more configuration is needed. The global CLI flags also need to be threaded through
to all commands via a shared context struct.

**Depends on:** T1.7 (interpreter uses config)
**Blocks:** T1.9, T1.10, T1.11 (CLI commands need global flags)

## Changes to `config/config.go`

### 1. Expand the `Config` struct

```go
type Config struct {
    // Journal settings
    DataFile       string `yaml:"data_file"`       // default: ~/.doublebook/data.journal
    DataDir        string `yaml:"data_dir"`         // default: ~/.doublebook/
    JournalName    string `yaml:"journal_name"`     // default: "data" (without extension)

    // Display settings
    DateFormat     string `yaml:"date_format"`      // default: "2006-01-02"
    Currency       string `yaml:"currency"`          // base currency, default: "USD"
    Theme          Theme  `yaml:"theme"`

    // Server settings
    APIPort        int    `yaml:"api_port"`         // default: 5555
    WebPort        int    `yaml:"web_port"`          // default: 4444

    // Account aliases
    Aliases        map[string]string `yaml:"aliases"`

    // Plugin settings
    Plugins        []string `yaml:"plugins"`        // list of plugin names to load
}

type Theme struct {
    PrimaryColor  string `yaml:"primary_color"`
    BorderStyle   string `yaml:"border_style"`
}
```

## Add `cli/context.go` — Global CLI Context

Create a new file `cli/context.go` that defines a shared context passed to all commands:

```go
package cli

// Context holds global flags and resolved config for a CLI invocation.
type Context struct {
    Config      *config.Config
    JournalName string // from --journal flag, overrides config
    BeginDate   string // from --begin flag (YYYY-MM-DD or YYYY/MM/DD)
    EndDate     string // from --end flag
    Verbose     bool   // from --verbose flag
}

// NewContext creates a context from the loaded config and parsed global flags.
func NewContext(args []string) (*Context, []string, error)
```

`NewContext` should:

1. Scan `args` for global flags: `--journal NAME`, `--begin DATE`, `--end DATE`, `--verbose`
2. Remove matched flags from args, return the remaining args
3. Load config using `config.LoadConfig()`
4. Override `config.JournalName` if `--journal` was provided
5. Normalize date formats: `YYYY/MM/DD` → `YYYY-MM-DD`
