# T4.1 — Multi-Currency Support and Exchange Rates

## Goal
Implement multi-currency support: detect non-base-currency amounts during import/insert,
fetch historical exchange rates from the Frankfurter API (free, no API key), cache
them locally, and store converted amounts as metadata in the journal.

## Context
Users spend in multiple currencies (BGN, EUR, GBP, etc.). When recording or importing
such transactions, DoubleBook should automatically look up the exchange rate for that
date, record it in the journal for historical accuracy, and use it for reporting in
the base currency.

**Depends on:** T1.3 (AST — Amount.Currency), T1.8 (config — base currency)
**Blocks:** T4.2 (API), T4.3 (web UI needs currency data)

## Create `currency/exchange.go`

### API: Frankfurter

Documentation: https://api.frankfurter.app/

```
GET https://api.frankfurter.app/2025-01-15?base=USD&symbols=BGN,EUR,GBP

Response:
{
  "amount": 1,
  "base": "USD",
  "date": "2025-01-15",
  "rates": {
    "BGN": 1.9558,
    "EUR": 0.96823,
    "GBP": 0.80853
  }
}
```

### Structs

```go
package currency

// ExchangeRate holds a single currency rate.
type ExchangeRate struct {
    Date         string
    FromCurrency string
    ToCurrency   string
    Rate         float64
}

// RateProvider fetches exchange rates.
type RateProvider interface {
    GetRate(date, fromCurrency, toCurrency string) (float64, error)
}
```

### Frankfurter client

```go
// FrankfurterClient fetches rates from api.frankfurter.app.
type FrankfurterClient struct {
    BaseURL    string // default: "https://api.frankfurter.app"
    HTTPClient *http.Client
}

func NewFrankfurterClient() *FrankfurterClient

// GetRate returns the exchange rate from fromCurrency to toCurrency on the given date.
// date format: "YYYY-MM-DD"
func (f *FrankfurterClient) GetRate(date, fromCurrency, toCurrency string) (float64, error)
```

Implementation:
```
URL: {BaseURL}/{date}?base={fromCurrency}&symbols={toCurrency}
```

Handle edge cases:
- If `fromCurrency == toCurrency` → return `1.0, nil` immediately
- If the date is a weekend/holiday, the API returns the nearest previous business day
- HTTP errors → return descriptive error
- Non-2xx response → return error with status code
- Use a 10-second timeout on the HTTP client

## Create `currency/cache.go`

### File-based cache

```go
// RateCache is a file-backed cache for exchange rates.
type RateCache struct {
    Path   string
    rates  map[string]float64 // key: "date|from|to"
    mu     sync.RWMutex
    dirty  bool
}

// NewRateCache opens or creates a rate cache at the given file path.
func NewRateCache(path string) (*RateCache, error)

// Get returns a cached rate or (0, false) if not found.
func (c *RateCache) Get(date, from, to string) (float64, bool)

// Set stores a rate in the cache and marks it as dirty.
func (c *RateCache) Set(date, from, to string, rate float64)

// Save flushes the cache to disk.
func (c *RateCache) Save() error

// Load reads the cache from disk.
func (c *RateCache) Load() error
```

Cache file format: JSON file at `~/.doublebook/rates.json`:
```json
{
  "2025-01-15|USD|BGN": 1.9558,
  "2025-01-15|USD|EUR": 0.96823,
  "2025-01-16|USD|GBP": 0.80853
}
```

## Create `currency/currency_test.go`

```go
func TestGetRateSameCurrency(t *testing.T) {
    // USD → USD should return 1.0 without making any HTTP request
    client := &FrankfurterClient{}
    rate, err := client.GetRate("2025-01-15", "USD", "USD")
    if err != nil { t.Fatal(err) }
    if rate != 1.0 { t.Errorf("expected 1.0, got %f", rate) }
}

func TestCacheRoundTrip(t *testing.T) {
    // Write a rate, save, reload, verify it's there
    tmp := t.TempDir()
    cache, _ := NewRateCache(filepath.Join(tmp, "rates.json"))
    cache.Set("2025-01-15", "USD", "BGN", 1.9558)
    cache.Save()

    cache2, _ := NewRateCache(filepath.Join(tmp, "rates.json"))
    cache2.Load()
    rate, ok := cache2.Get("2025-01-15", "USD", "BGN")
    if !ok { t.Fatal("rate not found") }
    if rate != 1.9558 { t.Errorf("wrong rate: %f", rate) }
}

func TestAnnotateAmount(t *testing.T) {
    s := AnnotateAmount(100, "BGN", 51.16, "USD", "2025-01-15", 0.5116)
    if !strings.Contains(s, "converted") { t.Error("missing 'converted'") }
    if !strings.Contains(s, "BGN") { t.Error("missing currency") }
}
```
