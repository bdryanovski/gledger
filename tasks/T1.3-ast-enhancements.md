# T1.3 — Enhance AST Types

## Goal

Extend the AST data structures to support tags, metadata, unique IDs, multi-currency
amounts, and implied (omitted) posting amounts — all required for hledger compatibility
and the DoubleBook feature set.

## Context

The current AST (`ast/ast.go`) only has minimal types: `Transaction`, `Posting`, and
`Amount`. Before enhancing the lexer and parser, the target data structures must be
defined. All other packages depend on these types.

**Depends on:** T1.1 (module rename), T1.2 (bug fixes)
**Blocks:** T1.4 (lexer), T1.5 (parser), all downstream packages

---

## Changes to `ast/ast.go`

### 1. Enhance `Amount`

Current:

```go
type Amount struct {
    Value    float64
    Currency string
}
```

Add:

- `IsNegative() bool` — returns `Value < 0`
- `Abs() Amount` — returns amount with positive value
- `Negate() Amount` — returns amount with negated value
- `Add(other Amount) (Amount, error)` — adds two amounts, returns error if currencies differ
- Update `String()` to handle various currency formats:
  - `USD`, `$` → `$1,234.56`
  - `GBP`, `£` → `£1,234.56`
  - `EUR`, `€` → `€1,234.56`
  - Other (BGN, etc.) → `1,234.56 BGN`

### 2. Enhance `Posting`

Current:

```go
type Posting struct {
    Account string
    Amount  Amount
}
```

Add:

```go
type Posting struct {
    Account      string
    Amount       Amount
    AmountOmitted bool            // true when no amount was specified (implied balance)
    Tags         map[string]string // inline tags parsed from posting comment
    Comment      string           // raw comment text on the posting line
}
```

### 3. Enhance `Transaction`

Current:

```go
type Transaction struct {
    Date        string
    Description string
    Postings    []*Posting
}
```

Add:

```go
type Transaction struct {
    Date        string
    Description string
    Postings    []*Posting
    Tags        map[string]string // key:value tags from comment lines
    ID          string            // unique ID from "; id: <hash>" comment
    Comment     string            // any other comment lines attached to this transaction
    Status      string            // "", "!", "*" — pending/cleared markers
}
```

### 4. Update `IsBalanced()` to handle implied amounts

When exactly one posting has `AmountOmitted = true`, the transaction is considered
potentially balanced — the omitted amount is the negation of the sum of all other postings.

Update `Balance()` to:

- Count postings with `AmountOmitted = true`
- If exactly 1 omitted posting: compute its implied amount as `-sum(all other postings)`
  and return the map including the implied amount
- If 0 omitted: behave as before (sum everything, check near-zero)
- If >1 omitted: return an error (cannot determine multiple implied amounts)

Update `IsBalanced()` to use the new logic.

Add a new method:

```go
// FillImpliedAmounts sets the Amount on any posting with AmountOmitted=true.
// Returns error if more than one posting has an omitted amount.
func (t *Transaction) FillImpliedAmounts() error
```

### 5. Add `TokenType` constants for new tokens

Add the following new token types that the enhanced lexer will produce:

```go
TOKEN_STATUS    // "!" or "*" at start of transaction line
TOKEN_TAG_KEY   // key part of a "key: value" tag in comments
TOKEN_TAG_VALUE // value part of a tag
TOKEN_CURRENCY  // 3-letter currency code (BGN, EUR, GBP, etc.)
```

### 6. Add helper constructors

```go
// NewTransaction creates a new transaction with initialized maps
func NewTransaction(date, description string) *Transaction

// NewPosting creates a posting with initialized maps
func NewPosting(account string, amount Amount) *Posting

// NewOmittedPosting creates a posting with no amount specified
func NewOmittedPosting(account string) *Posting
```

### 7. Add `String()` / serialization methods

The interpreter currently handles serialization in `SaveToFile`. Move the core
string formatting logic into AST methods:

```go
// String returns the hledger-compatible text representation of the transaction
func (t *Transaction) String() string

// String returns the posting line as it would appear in a journal file
func (p *Posting) String() string
```

Format for `Transaction.String()`:

```
YYYY-MM-DD [status] Description  [; comment]
[; tag: value]
    account:name    $amount  [; comment]
    account:name    $amount
```
